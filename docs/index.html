🔥 连接 Firebase

首次使用需要配置 Firebase，永久免费，无需绑卡。按以下步骤操作：

  1. 打开 Firebase 控制台，用 Google 账号登录
  2. 点击"创建项目"，名称随意填，全程默认下一步
  3. 左侧菜单选"Realtime Database" → "创建数据库" → 选"测试模式"
  4. 点击顶部 ⚙️ 项目设置 → 滚到底部"您的应用" → 选 Web(</>) 图标注册应用
  5. 复制显示的 firebaseConfig 代码，粘贴到下方框中
