Render 部署指南

永久免费 · 无需信用卡 · 支持 WebSocket 实时协作

部署概览

  • 注册 Render 账号（GitHub 一键登录，30秒）
  • 获取 API Key（1分钟）
  • 把 API Key 发给 AI 助手，自动完成部署
  • 获得公网访问地址，分享给团队使用
1

注册 Render 账号

打开 Render 官网，点击右上角 "Sign Up"，用 GitHub 或 Google 一键注册（免费，不需要信用卡）：

→ Render 官网注册
2

获取 API Key

登录后，进入 Account Settings → API Keys，点击 "Create API Key"：

→ 创建 API Key

复制生成的 API Key（格式类似 rnd_xxxxxxxxxxxx），粘贴到对话中发给我就行。

💡 收到你的 API Key 后，我会自动完成以下所有操作：
1. 创建 Web Service
2. 配置环境变量
3. 触发首次部署
4. 获取公网访问地址
全程无需你手动操作任何其他步骤。
3

等待自动部署完成

我会用 Render API 自动创建服务并部署代码，大约 2-3 分钟完成。部署完成后会给你一个类似这样的地址：

https://work-schedule-xxxx.onrender.com

把这个地址分享给团队成员，大家打开就能实时协作了！

⚠️ 关于免费版限制：
• 免费版在 15 分钟无访问后会自动休眠，下次访问约需等待 30-50 秒唤醒
• 首次部署和每次唤醒后会有一点延迟，属正常现象
• 数据持久化在服务端文件系统，服务重启后数据保留；但免费版每 30 天会重置一次磁盘（如需永久存储，后续可加免费 PostgreSQL 数据库）
★

已准备好的部署文件

所有部署配置文件已就绪，无需你额外准备：

server/ ├── package.json # Node.js 依赖 ├── server.js # 后端服务代码 ├── render.yaml # Render 部署配置 ├── Dockerfile # Docker 部署配置（备用） ├── .dockerignore # Docker 忽略文件 └── public/ └── index.html # 前端页面
