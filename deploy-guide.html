Railway 部署指南

两种方式任选其一，5 分钟搞定多人协作工作安排系统

方式一：Railway CLI 部署（自动）

如果你能从 Railway 网站获取一个 API Token，我可以直接用命令行帮你一键部署。

1

注册/登录 Railway

打开 railway.com，用 GitHub 或邮箱注册（免费）

2

生成 API Token

登录后访问 railway.com/account/tokens

点击 "Create Token"，名字填 deploy，复制生成的 Token

3

把 Token 发给我

在对话中粘贴你的 Token，格式如：

0a1b2c3d-4e5f-6789-abcd-ef0123456789

我收到后立刻帮你创建项目并部署。

💡 Token 只用于本次部署，不会存储。你也可以在部署完成后在 Railway 网站上撤销该 Token。
方案 B · 手动

方式二：Railway 网站手动部署

不需要 Token，全程在浏览器中操作

1

创建 GitHub 仓库

打开 github.com/new，创建一个名为 work-schedule 的仓库

设为 Public 或 Private 均可

2

上传项目文件

在你的 GitHub 仓库中，点击 "uploading an existing file"

把以下文件从 server/ 目录拖拽上传：

package.json server.js railway.json public/index.html .gitignore

⚠️ 注意：需要先在仓库中创建 public 文件夹，再把 index.html 上传到 public/ 目录下。GitHub 网页上传时，文件路径会保持文件夹结构。
3

在 Railway 创建项目

打开 railway.com/new

选择 "Deploy from GitHub repo"

4

连接 GitHub 仓库

授权 Railway 访问你的 GitHub，选择刚才创建的 work-schedule 仓库

Railway 会自动检测到 railway.json 配置，自动安装依赖并部署

5

获取公网地址

部署完成后，在 Railway 项目页面点击 "Settings" → "Networking" → "Generate Domain"

你会获得一个类似 work-schedule-production.up.railway.app 的公网地址

✅ 完成！把这个公网地址分享给团队，大家就能实时协作了

需要上传的文件清单

位于项目目录 server/ 下：

server/ ├── package.json # 依赖配置 ├── server.js # 后端服务 ├── railway.json # Railway 部署配置 ├── .gitignore └── public/ └── index.html # 前端页面

不需要上传 node_modules/ 和 tasks.json，Railway 会自动安装依赖，数据文件运行后自动生成。
